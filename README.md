🛍️ KNIT AND KEEP — Admin & User

Aplikasi E-Commerce Thrifting berbasis web dengan role User dan Admin.
Proyek ini dibuat untuk mempermudah transaksi jual beli barang thrifting dengan integrasi payment gateway untuk pembayaran online yang aman.

✨ Fitur
👤 User

🔐 Autentikasi & Profil — Registrasi, login, dan manajemen akun.

🏠 Dashboard — Melihat ringkasan transaksi dan aktivitas belanja.

📦 Katalog Produk — Jelajahi produk thrifting unik dan ramah kantong.

🛒 Keranjang & Checkout — Tambah ke keranjang, ubah jumlah, dan lakukan pembelian.

💳 Pembayaran Online — Integrasi dengan payment gateway (contoh: Midtrans) untuk pembayaran aman.

📍 Alamat Pengiriman — Simpan dan kelola alamat pengiriman.

🛠️ Admin

📦 Manajemen Stok — Tambah, edit, hapus, dan atur stok produk thrifting.

👤 Profile Admin — Kelola akun admin dan pengaturan.

💰 Status Pembayaran — Monitor status pembayaran dari pengguna.

🏗️ Teknologi yang Digunakan

Frontend: React.vite

Backend  :java / Spring Boot 

Database:  PostgreSQL

Authentication: JWT + Cookies

Payment Gateway: Midtrans
